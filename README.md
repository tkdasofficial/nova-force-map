# Nova Force Map

Build a 3D Game Map with "three.js" With Ultra-Realistic Sci-fi World. 

Need a Plain Marvel Ground, with obstacles like Containers, Blocks, Slopes, stairs, towers ect.. 

Make sure use only Geometry Shapes, Don't try to create a Real World Map. 

Map size 50x50 Meters.
